Claude Code plugin

Run these commands inside Claude Code:

/plugin marketplace add sammollaei/law-firm-skills
/plugin install law-firm-skills@sam-mollaei

Restart, then try /law-firm-skills:setup.

Plugin commands include the namespace, such as /law-firm-skills:morning.

Claude Code or Codex skill

From your project terminal, with Node.js 22.20+ and Git:

npx --yes skills@1.7.2 add sammollaei/law-firm-skills --skill morning --agent claude-code codex --copy

Restart in that project. Use /morning in Claude Code or $morning in Codex.

Review existing same-name skills before installing. Replace morning with '*' for the collection.
