If a skill does not appear

  1. Restart your AI host in the project where you installed it.
  2. Check whether you installed a standalone skill or the plugin. Claude plugin commands use /law-firm-skills:morning; standalone skills use /morning.
  3. Check for an existing skill with the same name. Confirm the actual source path before replacing anything.
  4. Try the fictional morning example in the installation guide before connecting business data.

Report a bug or suggest an improvement

Open a GitHub issue

Include the platform and version, skill name, steps to reproduce, expected result, and a fictional example. Remove sensitive details from logs and screenshots. Issues are public. Support is community based, with no response-time guarantee.

Share a result

Tell us which workflow helped and what remained difficult. Use fictional or anonymized examples that you have permission to share. A screenshot or claim is not permission to publish someone else's information.
