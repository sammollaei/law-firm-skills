Privacy and data handling

This notice describes Law Firm Skills, the open-source collection published by Sam Mollaei, and this project website.

The skill package

The installed skills contain instructions, examples, UI metadata, and two optional local calculation helpers. The full source-code archive also contains website sources, fictional tests, and release tooling. These files do not implement a service endpoint or database that collects your prompts, files, or business records for Sam Mollaei. The calculation helpers read a JSON file you supply and print calculations; they do not make network requests or write files. Release tooling writes local package files when a maintainer runs it. Your AI host may require its own account sign-in to install plugins; that does not create an account with Sam Mollaei.

Your AI host and connected tools

Your AI provider processes the prompts and files you give it under its own settings and policies. If you authorize a connected service, that service may also process relevant information. A skill may direct your assistant to use approved tools; the host controls their availability and permissions. Review those providers' terms before supplying confidential information. This collection does not provide email, calendar, CRM, or other account connections.

Website and installation

This static website is hosted by GitHub Pages. It contains no project analytics, advertising scripts, forms, or cookies set by this project. GitHub receives ordinary web requests and handles them under its own privacy policy. Downloads and repository activity are also hosted by GitHub. The optional skills CLI installer is a separate third-party tool that reports install telemetry by default; its supported opt-out is DISABLE_TELEMETRY=1 or DO_NOT_TRACK=1. Manual ZIP downloads do not run that installer.

Support

GitHub issues for this public project are public. Share a fictional reproduction, platform version, and error message with sensitive details removed. Do not post client records, personal information, credentials, or actual financial data. Public support content is handled by GitHub under its policies and can be read by the maintainer and others. This package does not maintain a separate user-data database.

For a privacy question, open a general issue without confidential details through the support page. If information is already public on GitHub, use GitHub's reporting and account controls as appropriate. Changes to this project's data handling will be reflected in an updated notice.
