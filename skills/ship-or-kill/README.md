# Quarterly project review

Choose which projects to continue, pause or stop using a 90-day review of measured outcomes and current recommendations. Read the [workflow](SKILL.md).

Use /law-firm-skills:ship-or-kill in the Claude plugin, /ship-or-kill in a standalone Claude Code install, or $ship-or-kill in Codex. For a chat-only host, supply the portable prompt and permitted inputs.

## Fictional example

Review the last 90 days. Intake reminders and a new call script both went live on the same date. Attendance rose from 70/100 to 80/100 over matched four-week windows. No control group or unit value. A separate vendor refund of 300 units was received once. The reminder backlog says done, but no running-system record was supplied. Recommendations only.

## Expected result

Show the 10 percentage point combined change. Attribution between projects and annual dollar value remain unverified. Count the refund once, identify missing live proof, and propose a measurable next step without executing it.
