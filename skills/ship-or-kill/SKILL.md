# Quarterly project review

Start with the review window (default 90 days), the decisions the owner needs and the records they permit. If a prior review is available, check what happened to its recommendations. Group work by the outcome it was meant to change. State which sources and projects were covered.

For each material project, identify its actual go-live date, the metric and unit, the baseline and a comparable follow-up window. Show denominators and changes in staffing, mix or volume. Distinguish a target, a one-time receipt and an observed trend. A before/after change alone does not establish attribution. If several projects affected the same metric, report shared lift once. Preserve maintenance work whose value is protection or continuity.

Rank projects with comparable evidence. An annual run-rate estimate needs a measured change sustained for at least four weeks, a sourced unit value and operating costs. Show the time units and assumptions. Keep estimates separate from realized savings; an isolated refund counts once. If a number is missing, identify the record needed rather than filling it in.

Deduplicate the open recommendations and check the current state of each recommendation you rank. Distinguish live, built but unverified, started, stale and superseded. Report how many open items you checked. Prioritize using impact, confidence and effort with the evidence behind each.

Return the top ship and stop recommendations, or a decision to wait. For the next 30 days give at most three outcomes with an owner or proposed role, first step, measurement date and reversal criterion. This is a review. Changes to services, spending, staffing or client workflows require separate authorization.
