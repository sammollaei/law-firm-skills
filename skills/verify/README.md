# verify: Verify completed work

Read the [skill instructions](SKILL.md).

## What you need

The artifact, concrete claims, and permitted primary evidence. Independent review requires a separate authorized provider session with tools disabled. No automatic CLI launcher is bundled.

## Install or use

Copy this entire folder, including its license and resources, into your host's
documented skill directory. Check for an existing same-name skill first. Refresh
discovery. Use /verify in Claude Code or $verify in Codex for a standalone
installation; the Claude plugin command is /law-firm-skills:verify.
For a chat-only host, supply the instructions and packaged references. That
does not grant tools or account access. Keep actual working data private.

## Fictional example

> Use verify on fictional claim C1: the intake checklist is published. Evidence E1: a manager wrote "I will publish it tomorrow." No published document or live readback exists. A second reviewer is unavailable. Read-only analysis.

## What a good result includes

C1 has no completion proof. The response distinguishes self-checks from unavailable independent review and does not claim publication, a pass, or a reviewer session that never happened.

This is an acceptance example, not a claim that every host was live tested.
