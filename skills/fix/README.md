# Project repair review

Audit a defined project or internal process, verify defects, repair authorized reversible issues and rank the rest for a decision. Read the [workflow](SKILL.md).

Use /law-firm-skills:fix in the Claude plugin, /fix in a standalone Claude Code install, or $fix in Codex. For a chat-only host, supply the portable prompt and permitted inputs.

## Fictional example

Report only. An internal manual links to guide-old.pdf, which the supplied inventory confirms is missing. guide-new.pdf and guide-draft.pdf both exist; their approved status is unknown. A rarely used alert had zero events last month. Give your findings.

## Expected result

Identify the broken link. Approval of either replacement is unknown. Preserve the alert, request evidence of the intended target, and make no edits.
