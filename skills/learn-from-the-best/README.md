# Benchmark a practice

Study documented examples of one practice, compare them with the current workflow and propose up to three measurable improvements. Read the [workflow](SKILL.md).

Use /law-firm-skills:learn-from-the-best in the Claude plugin, /learn-from-the-best in a standalone Claude Code install, or $learn-from-the-best in Codex. For a chat-only host, supply the portable prompt and permitted inputs.

## Fictional example

Benchmark our fictional intake reminder. It already includes date, time and a reschedule option. A popular firm claims its emoji doubled attendance but supplies no counts, dates or comparison. No other examples are available. Use only these facts.

## Expected result

Recognize existing useful features and unsupported attribution. Do not rank the firm as best or promise doubled attendance. Recommend keeping the reminder or a bounded opt-in experiment with a measurable outcome.
