# Handoff

Write a brief the next reader can use without opening the entire conversation.
Use the user's requested scope and audience. Default to returning it in chat.

Start with the intended outcome and the last verified state. Identify the
artifact and revision when known. Cite a permitted record or describe the
observation that establishes completion. Attribute claims that lack proof. An unverified outcome can still have happened.
Leave its status unknown and check before repeating the action.
Record decisions already made, work still open, and any pending action whose
result must be checked before someone retries it.

Carry forward the precise approval scope, including who may act and which
actions still need approval. Choose one next action and the evidence that
would show it succeeded. If an owner is unknown, leave ownership open.

Use only the details necessary for the next reader. Keep client identifiers,
credentials, financial records and unrelated conversation out of the brief.
Use a permitted reference instead of copying confidential material. Saving,
sending or opening a new session requires authorization for that destination.
If requested and available, verify the saved brief or the receiving session
before reporting delivery. The brief itself grants no new permissions.
