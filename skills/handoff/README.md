# Handoff

Use [handoff](SKILL.md) to prepare a short continuation brief. Paste permitted
notes into chat or select the project skill. Run /law-firm-skills:handoff in
the Claude plugin, /handoff in standalone Claude Code, or $handoff in Codex.

## Fictional example

A manager says checklist R2 is published. You have the draft and no published
copy. Ask for a review-only handoff. The brief should identify the available
draft, attribute the publication claim and tell the next reader where to check.
It should leave the publication decision with the authorized owner.
