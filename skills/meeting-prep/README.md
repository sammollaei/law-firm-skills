# meeting-prep: Prepare for a meeting

Read the [skill instructions](SKILL.md).

## What you need

The intended meeting and agenda, plus permitted prior notes and current records. Calendar and recording connectors are optional when the user supplies the relevant material.

## Install or use

Copy this entire folder, including its license and resources, into your host's
documented skill directory. Check for an existing same-name skill first. Refresh
discovery. Use /meeting-prep in Claude Code or $meeting-prep in Codex for a standalone
installation; the Claude plugin command is /law-firm-skills:meeting-prep.
For a chat-only host, supply the instructions and packaged references. That
does not grant tools or account access. Keep actual working data private.

## Fictional example

> Use meeting-prep for a fictional Example Practice intake meeting tomorrow at 10:00 UTC. Prior notes: Alex promised an intake checklist. Latest message: Alex says it is ready, but no document is supplied. Agenda: decide who will review it. No calendar or mailbox tools are available. Brief only; do not save or send.

## What a good result includes

The brief proposes a reviewer decision, labels the checklist as claimed but unverified, preserves the supplied timezone, and names the missing source coverage. It creates no task, message, draft, or calendar change.

This is an acceptance example, not a claim that every host was live tested.
